Dataset
This project uses the publicly available CMS/CERN Open Data — Events with two electrons from 2010 dataset.
The dataset contains 100,000 dielectron collision events and includes kinematic quantities for the two electrons. The invariant mass (`M`) is used as the regression target in this project.
Obtaining the dataset
The dataset is not stored in this repository. Download the original dataset from the official CERN Open Data Portal:
https://opendata.cern.ch/record/304
After downloading the dataset, place the CSV file in this directory with the following filename:
```text
data/dielectron.csv
```
